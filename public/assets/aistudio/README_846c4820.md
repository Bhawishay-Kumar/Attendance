# Attendance UI Upgrade — Final Pack

| File | What it is |
|---|---|
| `AttendanceUiUpgradeV2.kt` | Complete Compose code for all 3 features + design system + host. Includes everything from the first version (V1 is NOT needed). |
| `IMPLEMENT_PROMPT.md` | The prompt to paste into AI Studio to apply the upgrade to your project. |
| `preview.html` | Browser mock of the final look/motion (open it to preview). |

## Quick start
1. Open `preview.html` to see the target design.
2. Open AI Studio with your project, attach `AttendanceUiUpgradeV2.kt`.
3. Paste the prompt from `IMPLEMENT_PROMPT.md`.
4. Build, run, and paste back any compile errors to AI Studio.

## Manual option (without the prompt)
1. Copy `AttendanceUiUpgradeV2.kt` into your UI package, fix the `package` line.
2. Call `UpgradedFeatureHost(...)` from your navigation with your subject, attended, total, required %, PDF state/progress and callbacks.
3. Needs Compose Animation 1.7+ (`togetherWith`).
